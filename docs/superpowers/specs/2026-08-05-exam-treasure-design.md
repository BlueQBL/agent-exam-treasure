# 考试练习系统 — 设计文档

> 日期：2026-08-05
> 项目：agent-exam-treasure

---

## 1. 概述

纯前端考试练习系统。用户上传 Excel 题库后，可进行练习、模拟考试、错题巩固三种模式的学习。无需任何后端服务，双击 HTML 文件即可使用。

---

## 2. 技术方案

| 项目 | 选型 | 原因 |
|------|------|------|
| 文件结构 | **单 HTML 文件** (index.html) | 双击即开，零配置 |
| Excel 解析 | **SheetJS (xlsx)** via CDN | 浏览器端解析 .xlsx 标准库 |
| 数据持久化 | **localStorage** | 600+ 题纯文本约 200-300KB，上限 5-10MB 足够 |
| 页面框架 | **原生 JS (Vanilla JS)** | 无需构建工具，无框架依赖 |
| 图标方案 | **Unicode Emoji** | 不引入字体库，减少外部依赖 |

### 2.1 外部依赖

仅一项：`https://cdn.jsdelivr.net/npm/xlsx@0.18.5/dist/xlsx.full.min.js`

## 3. Excel 导入规范

### 3.1 列结构

| 列名 | 必填 | 说明 |
|------|------|------|
| 序号 | 否 | 行号，导入后自动重新编号 |
| 来源 | 否 | 题目出处，如"研发平台" |
| 题目 | **是** | 题目内容 |
| 选项A | 条件必填 | 选择题必填，判断/简答留空 |
| 选项B | 条件必填 | 同上 |
| 选项C | 条件必填 | 同上 |
| 选项D | 条件必填 | 同上 |
| 答案 | **是** | 选择题：A/AB/ABC/ABCD；判断题：对/错/正确/错误/T/F；简答题：得分点（\| 分隔） |
| 试题解析 | 否 | 答案解析 |

### 3.2 Sheet 与题型映射

- **多 Sheet 导入**：每个 Sheet 名包含关键词（单选/多选/判断/简答），自动映射为题型的 `type` 字段
- **单 Sheet 导入**：检查是否有"题型"列；若无则统一归为"选择题"
- 所有 Sheet 数据合并为一个统一题库

### 3.3 数据模型

```javascript
{
  id: Number,              // 自动编号（从导入顺序生成）
  source: String,          // 来源
  type: String,            // "单选" | "多选" | "判断" | "简答"
  question: String,        // 题目内容
  options: [String],       // 选项数组，判断题为 ["正确", "错误"]
  answer: String,          // 原始答案字符串
  explanation: String,     // 试题解析
  keyPoints: [String],     // 简答题得分点（从 answer 按 | 拆分）
}
```

## 4. 核心功能

### 4.1 首页 — 上传与数据管理

- **上传区域**：点击或拖拽选择 .xlsx / .xls 文件
- **加载提示**：解析后显示 `✅ 已加载 N 道题（单选 X/多选 Y/判断 Z/简答 W）`
- **数据管理**：
  - 查看全部题目列表（表格展示，可搜索）
  - 清除所有数据（重新导入）
  - 导出错题为 Excel（可选）

### 4.2 练习模式

| 特性 | 说明 |
|------|------|
| 题型筛选 | 开始前勾选要做的题型（单选/多选/判断/简答） |
| 乱序 | 独立开关：① 题目乱序 ② 选项乱序 |
| 答题方式 | 一题一页，选择答案后**立即显示对错 + 解析** |
| 导航 | [上一题] / [下一题]，底部显示进度 `5/50` |
| 完成后 | 显示本次正确率统计 |

### 4.3 考试模式

| 特性 | 说明 |
|------|------|
| 入口 | 点击"开始考试"弹出配置面板 |
| 配置项 | ① 选择题型范围 ② 抽取题数 ③ 每题分值 ④ 考试时长（分钟） |
| 答题方式 | 一题一页，**答题期间不显示对错** |
| 导航 | [上一题] / [下一题] + 右侧题号面板（可点击跳转，已答变色） |
| 交卷 | 全部答完显示"提交"按钮，或时间到自动交卷 |
| 结果页 | 总分、每题正误标记、正确答案及解析 |

### 4.4 错题练习模式

| 特性 | 说明 |
|------|------|
| 范围 | 仅包含**单选、多选、判断**，排除简答题 |
| 触发条件 | 练习或考试中答错的题自动进入错题本 |
| 移除条件 | 同一题**累计答对 3 次**才从错题本移除（防止蒙对） |
| 答题方式 | 一题一页，答完立即显示对错 + 解析 |
| 完成后 | 显示"错题已清零 🎉" |

## 7. 简答题判分逻辑

1. Excel 答案栏填写得分点，用 `|` 分隔，如："思极方舟|qiankun|微前端"
2. 导入时自动拆分为 `keyPoints` 数组
3. 答题时用户输入文本，系统对每个得分点做**关键词匹配**（不区分大小写）
4. 命中的得分点数量 / 总得分点数量 = 本题得分率
5. 简答题**不进入错题本**

## 8. 边界情况处理

| 场景 | 处理方式 |
|------|----------|
| 未上传题库直接点练习 | 提示"请先上传 Excel 题库" |
| Excel 格式不兼容 | 提示"无法解析文件，请检查格式" |
| 某些行缺少必填列 | 跳过该行并提示"第 X 行缺少题目/答案，已跳过" |
| 错题本为空时点错题练习 | 提示"暂无错题，去练习或考试吧！" |
| 考试时间到 | 自动交卷，统计已答题目得分 |
| 多选题选不全/选多 | 判分逻辑：全对满分，漏选或错选不得分 |
| 判断题答案格式不一致 | 兼容 "对/错/正确/错误/T/F" |
| 重新导入 Excel | 先清空本地数据再导入，防止重复 |
| localStorage 满 | 捕获异常，提示"存储空间不足，请导出数据后清除" |

## 9. 样式与主题

- 默认采用**清新蓝白主题**，适合长时间阅读
- 使用 CSS 变量，预留暗色/护眼模式切换接口
- 响应式设计，适配 PC 和 Pad 屏幕
- 题干和选项字号适中（16px+），阅读舒适
