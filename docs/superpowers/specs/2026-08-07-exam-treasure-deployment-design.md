# 考试练习系统 — 部署方案设计

> 日期：2026-08-07
> 项目：agent-exam-treasure

---

## 1. 概述

将纯前端考试练习系统部署到 GitHub Pages，实现通过网址直接访问。同时添加 Excel 题库模板下载功能，方便用户准备题库数据。

---

## 2. 部署方案

| 项目 | 选型 | 原因 |
|------|------|------|
| 托管平台 | **GitHub Pages** | 免费、零维护、与 Git 深度集成 |
| 域名 | `https://BlueQBL.github.io/agent-exam-treasure/` | 默认域名，无需额外配置 |
| 部署方式 | **main 分支根目录** | push 代码后自动部署 |
| CI/CD | 无需额外配置 | GitHub Pages 自动监听 push 事件 |

### 2.1 启用步骤

1. GitHub 仓库 → Settings → Pages
2. Source 选择 **Deploy from a branch**
3. Branch 选择 **main**，目录选择 **/ (root)**
4. Save 后等待 1-2 分钟即可访问

---

## 3. 功能增强

### 3.1 题库模板下载

在首页上传区域附近添加一个"下载模板"按钮，点击后生成并下载一个示例 Excel 文件，包含标准列格式和一两条示例数据。

**模板文件内容：**

| 来源 | 题目 | 选项A | 选项B | 选项C | 选项D | 答案 | 试题解析 |
|------|------|-------|-------|-------|-------|------|----------|
| 示例 | 以下哪个是编程语言？ | Python | HTML | CSS | JSON | A | Python 是通用编程语言 |
| 示例 | 2+2 等于几？ | 3 | 4 | 5 | 6 | B | 2+2=4 |

**实现方式：**
- 使用已引入的 SheetJS (xlsx) 库在浏览器端生成
- 无需额外的后端服务或 CDN 资源
- 点击按钮即时生成并下载

### 3.2 部署相关文件更新

- `.gitignore` — 确保无需添加额外忽略规则
- `README.md` — 更新部署说明，添加在线访问链接

---

## 4. 不需要的改动

| 不需要改 | 原因 |
|----------|------|
| 后端服务 | 纯前端应用，无需服务器 |
| 数据库 | 数据存储在浏览器 localStorage |
| 构建工具 | 单 HTML 文件，无需构建 |
| CDN 资源 | 已有 xlsx CDN，无需新增 |
| HTTPS 证书 | GitHub Pages 自动提供 |

---

## 5. 边界情况

| 场景 | 处理 |
|------|------|
| 自定义域名 | 用户可自行购买域名并配置 CNAME |
| Pages 部署失败 | 检查仓库名是否为公开仓库，main 分支是否存在 |
| 题库数据安全 | 数据仅存储在用户浏览器本地，不经过任何服务器 |
