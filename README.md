# 🎯 Exam Treasure — 考试练习系统

> 纯前端、零配置的考试练习工具。上传 Excel 题库即可开始练习、模拟考试、错题巩固。
> 双击 `index.html` 即可使用，无需任何后端服务。

---

## ✨ 功能一览

### 📂 一键导入 Excel 题库
- 支持 `.xlsx` / `.xls` 文件**拖拽**或**点击选择**上传
- 自动识别 **单选 / 多选 / 判断 / 简答** 四种题型
- 多 Sheet 导入：按 Sheet 名关键词自动映射题型
- 加载后展示各类题型数量统计

### 📝 练习模式
- 题型筛选（自由勾选要练的题型）
- **题目乱序** + **选项乱序** 独立开关，每轮随机排列
- 一题一页，答完**即时显示对错与解析**
- 完成后展示本轮正确率统计

### 📋 考试模式
- 可配置：题型范围、抽取题数、每题分值、考试时长
- 答题期间**不显示答案**，还原真实考试体验
- 右侧题号面板支持点击跳转，已答题目变色标识
- 支持 **主动交卷** 与 **时间到自动交卷**
- 交卷后展示总分、每题正误标记、正确答案与解析
- 考试记录持久化，可回顾历次成绩

### ❌ 错题巩固
- 练习和考试中答错的题目自动进入错题本
- **同一题累计答对 3 次**才移除（防止蒙对）
- 仅包含客观题（单选 / 多选 / 判断），排除简答题
- 答完即显对错与解析，清零后展示成就感 🎉

### 📊 统计面板
- 练习次数与综合正确率
- 按题型维度的正确率分布
- 历次考试记录回溯

### 📤 数据管理
- 查看全部题目表格，支持搜索
- 一键清除数据重新开始
- 导出错题为 Excel 文件

## 🚀 快速开始

### 使用方式

**只需要一个 HTML 文件：**

```bash
# 克隆仓库
git clone https://github.com/BlueQBL/agent-exam-treasure.git

# 直接双击打开
cd agent-exam-treasure
start index.html    # Windows
open index.html     # macOS
```

> 无需安装依赖，无需启动服务器，双击即开。

### 准备题库

按以下格式准备 **Excel 文件**（第一行为列名）：

| 序号 | 来源 | 题目 | 选项A | 选项B | 选项C | 选项D | 答案 | 试题解析 |
|------|------|------|-------|-------|-------|-------|------|----------|
| 1 | 研发平台 | 以下哪个是… | 选项1 | 选项2 | 选项3 | 选项4 | A | 解析内容 |
| 2 | 安全 | 判断：… | | | | | 对 | |

**列说明：**
- **题目**、**答案** 为必填列，其余可选
- 选择题：填写 **选项A ~ 选项D**
- 判断题：答案填写 `对 / 错 / 正确 / 错误 / T / F`
- 简答题：答案填写得分点，用 `|` 分隔（如 `思极方舟\|qiankun\|微前端`）
- **Sheet 名** 包含 `单选 / 多选 / 判断 / 简答` 关键词时自动识别题型

## 🛠 技术栈

| 项目 | 选型 |
|------|------|
| 文件结构 | **单 HTML 文件**（所有 CSS / JS 内嵌） |
| Excel 解析 | [SheetJS (xlsx)](https://cdn.jsdelivr.net/npm/xlsx@0.18.5/dist/xlsx.full.min.js) via CDN |
| 数据持久化 | **localStorage**（600+ 题约 200-300KB，上限 5-10MB） |
| 页面框架 | **原生 JavaScript (Vanilla JS)**，无框架依赖 |
| 图标方案 | Unicode Emoji，无外部图标库 |
| 样式方案 | CSS 变量 + Flexbox，响应式设计 |

## 🔧 辅助脚本

项目提供若干 Python 辅助脚本用于代码质量维护与问题排查：

```bash
# 检查关键解析逻辑是否正确
python check_code.py

# 批量修复已知问题（运行全部修复）
python fix_all.py

# 单独运行特定修复
python fix_filter.py    # 修复筛选功能
python fix_html.py      # 修复 HTML 结构
python fix_split.py     # 修复题型分割
```

## 📄 边界情况处理

| 场景 | 处理方式 |
|------|----------|
| 未上传题库直接操作 | 提示"请先上传 Excel 题库" |
| Excel 格式不兼容 | 提示"无法解析文件" |
| 行缺少必填列 | 跳过并提示"第 X 行缺少题目/答案，已跳过" |
| 错题本为空 | 提示"暂无错题，去练习或考试吧！" |
| 考试时间到 | 自动交卷，统计已答得分 |
| 多选题判分 | 全对满分，漏选/错选不得分 |
| 判断题答案格式不一致 | 兼容 `对/错/正确/错误/T/F` |
| 重新导入 | 自动清空旧数据再导入，防止重复 |
| localStorage 满 | 捕获异常，提示导出数据后清除 |

## 🎨 主题与设计

- **清新蓝白配色**（`#4A90D9` 主色调），适合长时间阅读
- CSS 变量驱动，预留**暗色/护眼模式**扩展接口
- 响应式布局，适配 PC 与平板屏幕
- 字号 16px+，交互元素最小触控区域 44×44px，移动端友好

---

## 🧠 设计理念

- **零配置优先**：一个 HTML 文件 = 完整应用，不挑运行环境
- **离线可用**：无后端依赖，Excel 解析和逻辑运算全部在浏览器完成
- **渐进增强**：核心功能纯前端即可运行，未来可扩展云端同步
- **开发者友好**：纯原生实现，无构建工具，改代码即改功能
